# Data dictionary

The harmonised table has one row per measure, location, year, sex, age, cause and metric combination. Required columns: `measure`, `location`, `year`, `sex`, `age`, `cause`, `metric`, `value`, `lower`, `upper`. Values and bounds must share units and scale. Preserve original source labels and hierarchy identifiers in the manifest. Do not mix counts with rates or crude estimates with age-standardised estimates.
