# Changelog

## 0.3.0 - 2026-11-09
- Tightened estimate validation to reject duplicate keys, blank categories and non-finite values.
- Added explicit endpoint-year support and annualised percentage change.
- Made DALY identity checks reject duplicate measure rows and report a pass/fail flag.
- Clarified the nested regional benchmark: Western Sub-Saharan Africa includes Nigeria.
- Separated the basic GBD neurological cause group from expanded cross-hierarchy nervous-system conditions.
- Separated vision impairment outcomes from ophthalmic causes.
- Added a dedicated estimand specification and detailed GBD 2023 acquisition protocol.
- Empirical results remain pending verified official source extracts.

## 0.2.0 - 2026-11-08
- Pinned the protocol to GBD 2023 (1990–2023).
- Added posterior-draw uncertainty utilities and paired draw safeguards.
- Added three-factor Shapley demographic decomposition.
- Added GATHER reporting tracker and data-acquisition gate.
